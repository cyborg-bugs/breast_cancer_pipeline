# Breast Cancer ML Pipeline

Machine Learning Cloud pipeline designed to predict breast cancer relapse using the METABRIC dataset. Developed with Azure ML SDK v2, featuring automated workflows for preprocessing, training (Random Forest & SVM), and model deployment.

## 📁 Estructura del Proyecto
* **components/**: Subcarpetas para encoding, escalado y selección de características.
* **data/**: Archivos del dataset METABRIC.
* **scripts/**: Archivos de inferencia y despliegue (`score.py`).

## 📊 Modelos Entrenados
* Random Forest (RF)
* Support Vector Machine (SVM)
